# Security policy

KitBag is pre-1.0. Security fixes target the latest `main`; older commits and
versions do not receive backports. Use the latest main when evaluating a fix.

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/TomaszJanusz/kitbag/security/advisories/new).
Include the affected commit, reproduction steps, impact and any suggested fix.
Do not post exploit details, credentials or personal configuration in a public
issue or pull request.

Private vulnerability reporting must first be enabled by the maintainer as
described in [governance](docs/governance.md). If the form is unavailable, open a
public issue asking for a private reporting channel, without vulnerability details.

This is a volunteer-maintained project. The maintainer aims to acknowledge
reports within seven days and provide an initial assessment within thirty days,
but cannot guarantee a response or fix deadline. Please coordinate disclosure
privately while a report is being assessed.
