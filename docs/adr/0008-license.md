# 8. Use the MIT License

- Status: Accepted
- Date: 2026-10-24

## Context and Problem Statement

kitbag is intended to be a free, public, open-source tool. Contributors need a
settled licence choice. The plan originally left MIT versus Apache-2.0 open;
the maintainer resolved that choice when creating the public repository.

## Decision Drivers

- A permissive licence for broad use and contribution.
- A simple, established licence text.
- Consistency with the repository's existing licence.

## Considered Options

- MIT.
- Apache-2.0.

## Decision Outcome

Use MIT, as decided by the maintainer on 2026-10-24 and recorded in plan §0 and
KIT-3. The repository's existing [LICENSE](../../LICENSE) is the authoritative
licence text and is retained unchanged.

Apache-2.0 was the considered permissive alternative, with more detailed patent
and notice provisions. The maintainer selected MIT; the earlier unresolved
MIT/Apache-2.0 wording does not leave this choice open.

### Consequences

- Distribute the existing MIT licence with the project.
- Preserve its copyright and permission notice as required by that text.
- Third-party dependencies retain their own licence obligations; this decision
  does not relicense them.
